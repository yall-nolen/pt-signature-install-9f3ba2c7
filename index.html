Purpose Transportation — Signature Install

How to use this page. Find your row below. If it shows photo choices, click the one that looks best first — that's the one that gets copied. Then click Copy — New Message and paste it into Outlook as your default signature for new emails. Click Copy — Reply and paste that in as your signature for replies and forwards.
  1. Open Outlook → File → Options → Mail → Signatures (or Settings → Accounts → Signatures on the new Outlook or web).
  2. New signature, name it Purpose - New Message, click here, paste.
  3. New signature again, name it Purpose - Reply, click Reply below, paste.
  4. Set New Message and Reply/Forward defaults to match.
